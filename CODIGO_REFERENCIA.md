# Código de referencia

El repositorio guía contiene la documentación de construcción. El código ejecutable completo se entrega por separado en tres snapshots:

- `sesion-01-v0.1.0`;
- `sesion-02-v0.2.0`;
- `sesion-03-v1.0.0`.

Esto permite que el alumno construya el ejercicio siguiendo los MD y que el docente conserve una versión de referencia para comparación o recuperación.
