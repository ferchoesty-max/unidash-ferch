# Pasos de clase — Sesión 1

1. Crear estructura de carpetas.
2. Construir `index.html` completo. No ocultar módulos “para después”.
3. Agregar tema y estilos responsive.
4. Crear `mock.data.js` como fuente única.
5. Renderizar tareas y finanzas.
6. Calcular las tarjetas resumen con datos mock.
7. Dibujar las gráficas con Chart.js.
8. Renderizar clima, divisas y noticias simuladas.
9. Conectar únicamente navegación y acciones demo.
10. Probar desktop, tablet y móvil.
