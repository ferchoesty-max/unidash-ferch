## UI completa + componentes + datos mock

**Duración:** 1 h 30 min  
**Versión:** `v0.1.0`

### Objetivo

Terminar la experiencia visual completa antes de conectar almacenamiento o APIs. Al finalizar ya se puede navegar por Dashboard, Tareas, Finanzas, Estadísticas, Divisas y Noticias. Los datos proceden exclusivamente de `mock.data.js`.

### Restricciones de esta sesión

```text
SÍ  → HTML, Tailwind, CSS, ES Modules, Chart.js, DOM, mock data, navegación
NO  → LocalStorage
NO  → fetch()
NO  → Geolocation API
NO  → API keys
```
